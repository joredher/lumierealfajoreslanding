# Keyword map – Lumière Artesanal

Language/market: Spanish, Colombia (`es-CO`). Business: handmade alfajores made in Yopal, Casanare, from Argentine recipes.

> **No search volumes are listed on purpose.** Volumes are not invented here. Validate each keyword with
> Google Search Console (real queries, once live), Google Keyword Planner, and Google Trends before
> committing to a page. Treat everything below as a hypothesis ranked by fit, not by traffic.

## How to read this
- **Intent**: *transactional* = wants to buy; *commercial* = comparing/choosing; *informational* = wants to learn.
- One primary keyword per page. Supporting keywords go in headings, body copy and image alt text **where they read naturally**. Never repeat a phrase just to repeat it.
- Titles ≤ 60 characters, descriptions ≤ 155 (all rows below were length-checked).
- **Status**: the site is currently **one page** (`/`). Only that row is live in code. The other rows are the plan for when you add pages (see "Adding pages").

## Avoiding cannibalisation
Each primary keyword belongs to **one** URL. The home page owns "alfajores artesanales Colombia"; `/cajas-de-alfajores` owns
"caja de alfajores"; don't write a second page for the same phrase. Link between pages with descriptive anchors
("las cajas de alfajores para regalar", never "haz clic aquí").

## Adding pages (technical note)
The site is a single-page React app. For separate indexable URLs you need real routes **and** pre-rendered HTML
(each page needs its own `<title>`, description, canonical and JSON-LD in the static HTML). Recommended path:
add `react-router` plus a static pre-rendering step (e.g. `vite-react-ssg`), extend the sitemap plugin in `vite.config.js`
with the new URLs, and give every page one `<h1>`. Say the word and I'll set it up.
